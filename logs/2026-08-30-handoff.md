## 3 · THE FIVE THINGS THAT WILL BITE

**THE BUNDLE.** `amenti-chat.js`, `amenti-voice.js`, `amenti-listen.js`,
`amenti-resolve.js` and `config.js` compile into **`amenti-core.bundle.js`**,
and the page loads the bundle. **Pushing a loose source does nothing.** Three
conversation modes were once written, tested by 141 assertions, pushed — and
were inert.

**THE WILDCARD RESET.** `amenti-tabs.css` line 279:
```css
body[data-page="terminal"] *{margin:0;padding:0;box-sizing:border-box;}
```
Two selectors. It **outranks any single class**, wherever that class appears.
Padding or margin inside the terminal needs `!important` or it silently becomes
zero. This cost four attempts at one gutter.

**DUPLICATE SELECTORS.** Four were created in one night, and in every case the
stale copy was later in the file and was the one that ran. **Run `csstest.js`
before handing over any CSS.**

**THE CACHE KEY IS `sha256(TTS_MODEL + voice + STYLE + TEXT)`.** `composeStyle`
and the chunk boundaries ARE the key. Move a byte and every rendered clip
orphans and is re-billed. `CHUNK_MAX 320` is locked. `gabriel: 700` is a
**deliberate fork** — do not unify it.

**THE `Voice` COLUMN IS NOT A VOICE NAME.** `Gender` picks Charon or Kore.
`Voice` and `Dialect` are prose fed to `composeStyle`. Getting this wrong would
orphan the archive.

## 6 · THE METHOD THAT WORKED

Stated plainly, because the difference between a good hour and a bad one last
session was entirely this.

**READ THE SOURCE BEFORE WRITING.** Every good result came from reading a file
first. Every bad one came from working from memory or from a screenshot.

**WHEN A SCREENSHOT SAYS NOTHING CHANGED, PROBE.** Do not edit again.
`probes/probe-ctx-gutter.js` found the wildcard reset in one run after four
edits had not.

**TEST AGAINST THE REAL THING.** A fixture you wrote tests the fixture. The BC
bug and a markdown renderer's broken bold both survived every fixture and died
on first contact with the live file.

**SUSPECT THE INSTRUMENT.** It was wrong at least six times last session — a
test that could not see the overlap it was built for, a regex matching
`max-width` inside a `width` check, a harness reading only stdout. When a check
fails on code you believe is correct, check the check.

**CITE BEFORE YOU BUILD.** Name the register, the brief or the ruling the work
rests on. If none can be named, the reading has not been done.
