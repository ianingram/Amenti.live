# CAPTAIN'S LOG · 29–30 AUGUST 2026
**Ingram Manor LLC · Amenti.live**

A session that began with Abraham Lincoln speaking in a woman's voice and ended
with every work in the library carrying a source. In between: a terminal rebuilt,
three manuals written, a nineteenth pane, and four instruments that did not
exist at the start of it.

It also contains a great deal of the assistant getting things wrong, which is
recorded in §V because a log that holds only the wins is a log nobody can trust
the rest of.

---

## I · WHAT WAS FOUND

### THE ROSTER WAS NEVER REACHING THE VOICE

Lincoln spoke as a woman. The cause was not a wrong voice chosen — it was **no
voice resolved at all**.

`amenti-voice.js` fetched the Google Sheet directly and had **nothing to fall
back on**. That fetch throws `Load failed` from the page, and an unresolved
figure falls to `VOICE_NAME_DEFAULT`, which is `Kore`. So a dead roster sounded
exactly like a deliberate casting choice for the entire cast.

**And the flagship had already solved it.** `Page1.html` logs its own load as
*"via ./names.csv (local, first)"* and then *"via the sheet (authoritative)"* —
the same repo, the same columns, the same 1,011 rows, unfetched by the one
module whose whole job depended on them.

> **TWO REGISTERS OF ONE THING, AND ONLY ONE OF THEM KNEW HOW TO SURVIVE.**

Fixed: `loadRoster` now reads `./names.csv` first and upgrades from the sheet
when it answers. The sheet's failure can no longer take the roster down.

### THE VOICE COLUMN IS NOT A VOICE NAME

Chased for an hour on a wrong assumption. `Gender` picks the engine voice —
Charon or Kore, the two Gemini voices. **`Voice` and `Dialect` are prose fed to
`composeStyle()`**, shaping how that voice performs. Lincoln and Caesar are the
same engine voice, made distinct by accent and character.

`composeStyle` is in the cache key. Had the assistant "fixed" this by passing
`fig.voice` as the engine voice, **the entire archive would have orphaned** for
a design that was already correct.

### THE WILDCARD RESET

`amenti-tabs.css` line 279:

```css
body[data-page="terminal"] *{margin:0;padding:0;box-sizing:border-box;}
```

Two selectors, so it **outranks any single class** wherever that class appears.
A gutter was raised four times — 20, 28, 30, 44 — and a console probe found the
computed value was **0px every time**. The number never arrived.

**The same file already documented this trap** in its codex block, and the
assistant edited past it repeatedly.

### FOUR DUPLICATE SELECTORS IN ONE NIGHT

`.term-mode-wrap`, `.term-ctx`, `.term-call`, `.term-mode` — each declared
twice, and in every case the stale copy sat later in the file and was the one
that ran. Work was tested, correct, and overridden by a copy of itself.

> **A DUPLICATE SELECTOR IS NOT A STYLE PROBLEM. IT IS A FILE WHERE THE THING
> YOU ARE READING IS NOT THE THING THAT RUNS.**

`csstest.js` now fails on any `.term-` selector declared twice. Its first
version named three selectors and missed `.term-ctx`; **a guard with a list
only catches what somebody already thought of.**

### THE ANNOUNCEMENT AND THE GREETING PLAYED TOGETHER

Two consecutive lines with nothing between them:

```js
AmentiDial.place();               // "Amenti Interface"
this.speak("I am here.");         // at the same instant
```

The engine's own `stopReading()` could not arbitrate, because each call waits on
`resolveVoice()` before scheduling — so both resolved, both scheduled onto the
AudioContext, and both sounded.

Fixed: the dial takes an `onRinging` hook and fires the greeting when the line
starts ringing. **The greeting is the answer to the ring, not a second
announcement.**

### THE `Links` COLUMN CITES NOTHING

All 1,011 rows carry a value and every one is the same shape:

```
https://en.wikipedia.org/wiki/Special:Search?search=<name>
```

A link to a **search box**, generated from the name. A column that looks
populated and holds nothing.

### 77 OF LINCOLN'S 82 WORKS HAD NO SOURCE

The most-quoted figure on the site, the least-sourced shelf. Not a mystery:
one book's table of contents, in that book's order and editorial voice —
**Speeches and Letters of Abraham Lincoln, 1832–1865, ed. Merwin Roe, Project
Gutenberg #14721.** Four works had been pulled into their own files and cited;
the bulk import beside them never got the citation propagated.

It sat that way because **`probe-library.mjs` faithfully RECORDED those blanks
and nothing READ what it recorded**, and because:

> **AN EMPTY SOURCE STRING READS AS A FIELD RATHER THAN A GAP.**

### THE INDEX DOES NOT WALK THE ENGINE

`SOURCES.json`'s root rule is `^[^/]+\.(md|json)$`. **`amenti-voice.js`,
`amenti-chat.js`, `amenti-dial.js`, `amenti-doctrine.js` and the rest are
invisible to the index.** Found by `probe-serves.mjs` calling two of them
BROKEN when both exist.

### THE ROSTER STORES BC AS A NEGATIVE NUMBER

Caesar's `Death-Date` is `"-44"`, not `"44 BC"`. The posting gate's first
parser read it as the year 44 and would have held **every pre-Christian figure
in the cast** as within living memory. Found by running the test against the
live roster instead of a fixture.

### CAESAR MAY STILL BE IN THE WRONG VOICE — OPEN

The terminal displays **GAIUS JULIUS CAESAR**. `names.csv` holds **Julius
Caesar**. The voice resolver keys on that exact lowercased string. If the
terminal passes a name the roster does not carry, it resolves to nothing and
falls to the default — **the same fault as Lincoln's, on a different figure,
still live.**

**One console line settles it.** Not yet done.

### The terminal

`Page1.html` and `amenti-tabs.css`, ending at **`?v=24`**.

- **The shell has a ceiling.** `min-height:78vh` with no max let a
  thousand-name roster grow the grid row to thousands of pixels — the plate
  stretched, the input rail went off screen. `height` + `min-height:0` on every
  child. A grid child's default `min-height` is `auto` and refuses to shrink.
- **The context panel does not scroll; its upper half does.** `.term-ctx-scroll`
  takes the slack, `.term-mode-wrap` is a fixed foot. `margin-top:auto` was
  tried **three times** and cannot work here — it pushes into free space, and a
  box with `overflow-y:auto` sizes to its content and has none.
- **The MODE control**, moved four times: toolbar (read as an action), roster
  foot (the list scrolls through that space), input rail (in among the buttons),
  and finally the panel foot. Now a **full-width square-cornered plate at 14px**
  with **a colour per mode** — green character, gold counsel, blue tutor, violet
  witness, red adversary — driven by `data-mode` on the wrapper.
- **CALL is first on the rail**, by declaration. All four rail controls are
  injected with `insertBefore(hint)`, so they had been landing in whatever order
  their scripts happened to run.
- **The ASCII pyramid removed.** The same seven lines under every figure, under
  a `▸` header like CONNECTION and DOSSIER, which say something.

### The hall

returns.** Most of the work is knowing when *not* to fire: controls are exempt,
a drag is not a click, a finished text selection is not a click. Escape restores
it, and focusing any field restores it, so an answer can never arrive into a
pane nobody can see.

**Hume — the numbers are found.** 13 works read *"Project Gutenberg"* with no
number after them. All six parts confirmed, each with its own subtitle:

```
Part A  #19211   From the Britons of Early Times to King John
Part B  #19212   From Henry III. to Richard III.
Part C  #19213   From Henry VII. to Mary
Part D  #19214   From Elizabeth to James I.
Part E  #19215   From Charles I. to Cromwell
Part F  #19216   From Charles II. to James II.
```

Every work in the room lands in the part its subtitle covers. **But the 13 span
six parts**, and `cite.js --section` filters by the room's own sections
(*"Portraits from the History of England"*), not by part — so this needs six
runs some other way, or the manifest edited directly. **Note: the Cromwell room
already cites Part E as #19215** — the right number was in one room and not the
other.

**Eight more rooms are THIN**, all "which edition":
akhenaten 6 (Weigall) · confucius 6 (Legge) · plato 6 (Jowett) ·
seneca 6 (Aubrey Stewart) · john-milton 6 (names no edition at all) ·

frederick-douglass 6 (a year, no edition)

**Three instruments that never run.** `probe-post.mjs`, `probe-serves.mjs` and

## V · THE ASSISTANT'S OWN ERRORS

Recorded because the pattern is more useful than any single instance.

**BUILT BEFORE LOOKING, TWICE.**
`WORKS.semantics.json` — a corpus register with six figures and every url null,
written while `LIBRARY.json` held **550 works with translator, edition and
Gutenberg number**. Its path was in the unindexed list, read twice, passed over
both times.
`MANUAL.md` — a reader's manual when an operator's map had been asked for.

**EDITED THE VOICE ENGINE WITHOUT READING THE SPEECH DOCTRINE.** Corrected only
when the captain sent it back to read. The doctrine names this exact failure.

**APPLIED `margin-top:auto` THREE TIMES** to a container that could never honour
it, rather than questioning the mechanism.

**RAISED A GUTTER FOUR TIMES** from screenshots. A probe found the cause in one
run. Should have probed after the first screenshot said nothing changed, not the
fifth.

**THE INSTRUMENT WAS WRONG, REPEATEDLY.** An overlap test that could not see the
overlap (two utterances in one tick share a `Date.now()`). A regex matching
`max-width:100%` inside a `width:100%` test. A selector lookup by substring. A
harness reading only stdout when the tool writes to stderr. `grep -c FAIL`
counting a section heading. **At least six times.**

**FIXED ONE COPY OF A FAULT AND CALLED IT FIXED.** `ANY_ID` corrected while
`ID_ATTR` two lines up had the identical bug.

**WROTE `|| echo "empty=1"` IN A WORKFLOW** — which swallows every non-zero
exit, so a crash and a real finding report identically. **That is the four-day
blindness written small, three hours after discussing it.**

**BUILT A CLI FOR SOMEONE WITH NO TERMINAL.** `cite.js` was written as a command
to type, and the captain works from GitHub in a browser. Should have asked how
he works before writing it. Corrected as `cite-a-room.yml`.

> **A TOOL THAT CANNOT BE REACHED BY THE PERSON WHO NEEDS IT IS NOT A TOOL;
> IT IS A FILE.**

**SAID A REGISTER WAS "UNDESCRIBED" AS IF THAT WERE A FINDING**, when the true
statement was simpler: *the texts are in nothing I can see.* A dodge in the
shape of an insight.

**FETCHED `SOURCES.json` AT FULL SIZE THREE TIMES** after it was already known
to be cached and stale. Real context spent for nothing.
